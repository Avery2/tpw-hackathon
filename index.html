Turning program activity into proven impact.

A framework for joining in‑prison program data to parole and recidivism records — built with Transformative Programming Works.

⚖️ Justice Reform. California's corrections department spends under one percent of its budget on rehabilitation. Transformative Programming Works advocates for them across 120 organizations, but so far can only track process data — such as who enrolled and how long a class ran.

Join disjoint records such as parole and recidivism data into a framework TPW, and nonprofits generally, can use to track impact.
