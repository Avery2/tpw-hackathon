TPW Collective Impact Report

Data Collection Form: Field Glossary and Submission Instructions

Prepared for internal review by Rick Olesek and Kim Moore | June 2026

Purpose

This document defines every field in the TPW Collective Impact data collection form and provides submission instructions for member organizations. It is intended to ensure data consistency across all submitting organizations so the resulting dataset is reliable enough to use for advocacy, facility mapping, and funder reporting.

Please review and confirm that field definitions match how your organizations classify and track program data. Notes and proposed changes are marked throughout.

| ★ Proposed Column Rename for ReviewColumn H is currently labeled "Total Programming Hours". This label is ambiguous — it could be read as total hours across all participants. The suggested rename is "Course Hours (per Participant)", which makes clear that this field captures the total hours required for one person to complete the program. The calculated column (Column L) would then be renamed "Total Participant Hours Delivered" to reflect that it aggregates across all completions. Please confirm or suggest an alternative. |

Submission Instructions

What to submit: One row per program cycle. A program cycle is one run of one program at one facility.

Timeframe: Submit data for your most recently completed program year. If your fiscal year does not align with the calendar year, use the most recent 12-month period for which you have complete records.

Status filter: For this first data pull, only submit rows with a Schedule Status of Completed. Planned and In Progress programs should be left out until they finish.

One row per yard: If your organization runs the same program at multiple yards within one facility, submit a separate row for each yard.

Historical data: You are not limited to WRIGHT Grant-funded programs. Submit all completed rehabilitative programming under the TPW umbrella for the reporting period.

Calculated fields: Columns L and M are calculated automatically. Do not edit them.

Questions: If a field does not apply or you are unsure how to classify something, use the Notes column (Column N) to flag it. We will resolve edge cases together before broader distribution.

Frequently Asked Questions

What is the difference between a course, a cohort, and a class?

For this form, use one row per program cycle — meaning one run of one curriculum at one facility, regardless of what your organization calls it internally. Whether you call it a course, cohort, or class, each distinct offering with its own start date, end date, and participant group is one row.

What if our program ran across two calendar years?

Submit start and end dates as they actually occurred. The calculated Program Year field will assign the program to the year it started. If the majority of hours were delivered in the following year, flag it in the Notes column and we will handle the allocation consistently across organizations.

What if we do not track participants vs. completions separately?

Enter your best estimate in both columns and flag it in Notes. We would rather have approximate data with a clear note than no data at all. This is a first-cut dataset and will improve over time.

Should we include programs run by incarcerated facilitators or peer leaders?

Yes, include them. Do not attempt to separate out facilitator type at this stage. That distinction is deferred to a later phase of data collection.

What if we ran the same program at the same facility multiple times in the year?

Submit one row per cycle. If Defy ran two separate cohorts at San Quentin in 2025, that is two rows, each with its own start date, end date, and participant counts.
