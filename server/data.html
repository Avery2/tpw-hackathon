Downloads include submission history, not just the latest numbers. CSV opens in Google Sheets; JSON preserves the structured records. Older records without per-yard counts are marked in the CSV rather than filled with guessed numbers.

To open the CSV in Google Sheets: create a separate spreadsheet, choose File → Import → Upload, and turn off Convert text to numbers, dates, and formulas. Changes to that copy do not update the app.
