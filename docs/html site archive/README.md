# Archived static application

The retired HTML application, related tests, Apps Script receivers, mirrored website, intake tools, and old server implementation are retained under `legacy/` for reference.

The active Next.js application lives in `app/`, with shared helpers in `lib/`, backend code in `lib/server/`, and static assets in `public/`. Next.js serves only that public directory as static files.

Archived scripts retain historical paths and configuration. Review those dependencies before attempting to run them. Active development and deployment use the root package scripts.
